# Expansion plan: from evidence gaps to a bidirectional feasibility verdict

*November 9, 2026. Personal hobby and learning project planning document; AI-assisted drafting, owner-reviewed. This expands a theoretical research program, not a treatment program. Cost figures are planning-grade estimates pending written quotes; no figure here authorizes spending.*

## Overall objective this plan serves

The project's lead question: whether sustained, reversible drug modulation of melanin production can change iris appearance in both directions — blue → dark brown → the same person's original blue — while preserving tissue function. The [mechanism shortlist](mechanism-shortlist.md) establishes the three controls this requires: pigment **production**, pigment **persistence** (net loss and recovery of stored pigment), and the **optics** linking inventory to appearance. The November 2026 sweep confirmed every branch is blocked on the same class of missing observation: paired exposure/withdrawal data in one human pigment-cell system, which no published study provides for any named candidate.

Every goal, feature, step, resource and milestone below is judged by one test: does it move one of the three pillars from "hypothetical" toward "measured," or sharpen the decision about whether to continue?

## 1. Specific goals

| Goal | Measurable objective | Serves |
| --- | --- | --- |
| **G1. Comparative recovery resolved** | Paired exposure-and-withdrawal data for KT-939 and thiamidol (primary comparison), with free-compound-corrected synthesis-flux washout fits from at least three independent lines/donors. Deliverable: washout half-times with confidence intervals for both compounds in one system, plus the scaffold-retention decision-gate outcome. | Production pillar; closes the sweep's confirmed gap |
| **G2. Old-pigment tracking validated** | Heavy/light melanin isotope-ratio separation demonstrated in pigmented human melanocytes, with stated detection limits — feasibility gate 1 of the [paired protocol](paired-exposure-withdrawal-protocol.md). Fallback (melanosome pulse-chase) declared if it fails. | Persistence pillar; required to separate fixed pool vs replacement |
| **G3. Appearance relation quantified** | A reproducible model mapping pigment inventory (amount and compartment) to iris appearance, calibrated against published iris spectra and — if tissue access is secured — donor-eye measurements, with residuals and uncertainty stated. | Optics pillar; inventory change is not appearance change without this |
| **G4. Production-up on/off cycle measured** | At least one production-up candidate (ampyrone or the SIK comparator) completes a measured withdrawal cycle in human cells or 3D tissue, with free-compound accounting. | Blue → brown half of the bidirectional goal |
| **G5. Human iris-cell foundation** | Either a native iris-melanocyte mechanistic study registered, or a sourced iris-derived melanocyte line with a declared atlas extension checking OCA2/TPC2/TYR machinery beyond the fixed original panel. | All pillars; every current cell result is melanoma or skin derived |
| **G6. Evidence engine sustained** | Quarterly sweep cadence kept; every added citation verified against publisher or PubMed records; zero unflagged non-primary sources in the register. | All pillars; keeps priorities honest at low cost |
| **G7. Integrated verdict** | Bidirectional feasibility verdict v2: all five branches re-ranked on new data, with explicit go/no-go criteria for a Phase-2 (pre-ocular) program and documented reasons if the answer is no. | The project's actual deliverable: a defensible answer, not a treatment |

## 3. Implementation steps

Sequenced by dependency, not calendar optimism: each phase's exit gate must pass before its successor spends money.

**Phase 0 — Groundwork (agent-executable now).**
- S0.1 Register the missing method literature: TPC2-A1-P active-range sources and heavy-tyrosine melanin-labeling precedents, verified per the usual rule.
- S0.2 Draft core-facility quote-request packages from the protocol: experiment list, readouts, controls, deliverables, and the three feasibility gates as a separately quoted first stage.
- S0.3 Draft the optics-model specification and its calibration data requirements (which published spectra, which error model).
- S0.4 Stand up the milestone/budget ledger (F6).
*Exit gate: quotes requested from at least two facilities; S0.1 rows verified in the register.*

**Phase 1 — Feasibility gates (contracted).**
- Old-pigment isotope pre-labeling validation (gate 1), intracellular free-compound assay validation per candidate (gate 2), ampyrone solubility window (gate 3).
- Revise the protocol to v1.1 with gate results; a gate failure triggers its declared fallback rather than ending the program.
*Exit gate: each of the three gates documented pass/fail with numbers; revised protocol committed.*

**Phase 2 — Paired washout matrix (contracted).**
- Six-day arm first (matches registered endpoints), then the 21-day mature-pigment arm; KT-939/thiamidol pairing is the primary comparison, ampyrone and TPC2-A1-P arms follow as budget allows.
- Agent-run ingestion and fitting (F5); decision gates evaluated against predeclared criteria.
*Exit gate: G1 delivered — comparative washout fits with CIs; scaffold-retention gate answered with data.*

**Phase 3 — Optics module (mostly local).**
- Implement and calibrate the inventory→appearance model on published spectra; donor-eye measurements only if tissue access and budget permit.
*Exit gate: G3 delivered — calibration residuals stated; limitations documented.*

**Phase 4 — Iris-cell foundation (literature-first, wet-lab optional).**
- Register native iris-melanocyte evidence if it exists; otherwise evaluate sourcing a line and running the declared atlas extension.
*Exit gate: G5 delivered — either registered evidence or a sourced-line decision recorded.*

**Phase 5 — Integration.**
- Bidirectional feasibility verdict v2; re-rank all five branches; update shortlist, README and register; record go/no-go for any Phase-2 (pre-ocular) program.
*Exit gate: G7 delivered — verdict doc with every re-ranking traceable to a dataset or registered source.*

## 4. Required resources

**Personnel.** This is a personal hobby project with no employees; roles are:
- **Owner**: direction, budget authority, external contacts (facilities, eye banks), and personal review of agent-run work. AI-assisted development stays visible in public overviews.
- **AI research and code agents**: literature sweeps, citation verification, data extraction, modeling and fitting, document maintenance. Runs on existing subscriptions and APIs.
- **Contracted academic core facility or CRO**: the only place wet-lab work happens — cell culture, isotope tracing, LC-MS/MS, 3D tissue. No home lab is contemplated.
- **Optional collaborators** (unpaid or consultative): a melanocyte-culture adviser, an optical-modeling adviser, an eye-bank tissue coordinator.

**Tools.** Existing repo workbench (Python, RDKit, reproducible receipt discipline), the scholar/web MCP stack, secrets-guard; external: facility LC-MS/MS, spectrophotometry, and isotope capability. New local tooling is limited to the optics module and fitting pipelines (F5), both built on the existing analysis framework.

**Budget (planning-grade; quotes supersede all figures).**
| Stage | Rough range | Notes |
| --- | --- | --- |
| Phase 0 | $0–100 (agent/API costs only) | Fully agent-executable |
| Phase 1 gates | $8k–30k | Method development and validation at core-facility rates; the separately quoted first stage |
| Phase 2 washout matrix | $20k–75k | Scales with arms × timepoints × donors; staged so the KT-939/thiamidol pairing lands first |
| Phase 3 optics | $0–500 compute; $5k–20k if donor-eye | Donor-eye range reflects tissue-acquisition and analysis variance |
| Phase 4 iris-cell | $1k–5k line sourcing, or $0 literature-only | Literature-first policy |
| Contingency | +25–30% | Standard for planning-grade estimates |
*Stages are severable: each phase produces standalone value, and the program is designed to pause cleanly at any gate if budget or interest ends. That is a feature, not a concession — the register, protocol and verdict documents keep their value regardless.*

**Other inputs.** Eye-bank research-tissue access (Phase 3 upgrade), written facility quotes, and the owner's review time — roughly a weekly review cadence during active phases.

| Milestone | Target | Criteria (measured, not felt) |
